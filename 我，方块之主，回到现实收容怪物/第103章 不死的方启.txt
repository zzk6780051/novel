第103章 不死的方启
　　既然1440老头瞬移的很快，那么方启不介意……分割整个世界。
　　方启表示，找人帮忙要先给对方一点面子。
　　所以，方启直接飞上云霄，用方块在空中摆出了一行大字。
　　【死之三兄弟，我们谈谈。】
　　结果可想而知。
　　1440老头还是在疯狂瞬移，死之三兄弟根本没理会他。
　　可能是看他太弱了吧。
　　方启无奈叹息，这一次，他掏出了命令方块。
　　这一次，他要试一试自己对现实世界的权限，能做到哪一步。
　　【/gamerule doTeleport false
　　/execute in minecraft:overworld run execute anchored eyes positioned as @e at @s run data merge entity @s {Tags:}
　　/execute in minecraft:overworld run execute at @a positioned as @s run data merge entity @s {Tags:}
　　/execute as @e at @s run tp @s ~ ~ ~
　　/execute as @e at @s run tag @s remove no_tp】
　　【禁止任何生物（包括玩家）在主世界维度（地球范围）内进行任何形式的瞬间移动】
　　随着最后一行指令敲下，命令方块启动。
　　然后，1440老头身上的光柱，瞬间停在了原地。
　　好机会。
　　方启下一秒，立刻传送到1440老头身旁。
　　老者一脸疑惑，看着停下来的自己，然后又抬头和刚刚传送过来的方启对视。
　　“是你让我停止了传送？”
　　老人的声音十分沙哑，看脸上的表情也充满了疲惫。
　　死之三兄弟送给了他永生，但是却没有给他同样的相应的青春。
　　老人一直保持着，这样一副年迈的样子，不知过了多少岁月。
　　方启灵光一闪。
　　话说回来。
　　这老头要是有腰间盘，那是不是就说明，他是唯一一个得了腰间盘上千年的病人？
　　这不得疼死？
　　方启轻咳一声：“是我，我来找你……身边的死之三兄弟。”
　　老者听到方启的话，立刻摇了摇头。
　　“别，千万不要。”
　　“你很厉害，但是你肯定没有死之三兄弟更加厉害。”
　　“快走吧孩子，这么多年，因为我而死的人已经够多了。”
　　老人说的极为真诚。
　　然而下一秒，死之三兄弟出现了。
　　他们并没有显示自己的身形，方启是通过他们造成的影响，注意到他们降临的。
　　因为老头身上的定位光柱，瞬间消失了。
　　老人先是皱了皱眉，似乎在听谁说的话。
　　然后老人看向方启，无奈的说到：“他们杀死了【我被定位】这个概念。”
　　“现在他们要杀死【我不能瞬移】这个概念，以及……杀死你。”
　　方启嗤笑一声，直接在原地放了个床。
　　“我倒是想看看，是他们更厉害，还是MC世界的规则更厉害。”
　　“杀死我，他们大可以试一试！”
　　方启这句话说的，豪气冲天。
　　实则方启的内心也没有底。
　　虽然MC展现出了能够同化，万物皆死【结束叙事】的极高位格。
　　但是真面对上死之三兄弟，方启心底还是没有底。
　　随着方启话音落下，方启只觉得自己眼前一花，然后面前的画面，瞬间出现了死亡后的复活选择界面。
　　这是之前没出现过的。
　　之前方启死亡之后都是直接复活。
　　现在方启有了完整的界面，反倒有些不适应起来。
　　点击复活，方启的身体从红床旁边瞬间诞生。
　　1440老人看到这一幕，整个人都愣住了。
　　方启竟然，从死之三兄弟的祸害之后活过来了。
　　死之三兄弟的实力，1440老人是见过的。
　　被他们三兄弟杀死的存在，就没有任何一个能够活下来。
　　三千年的女成，老者见识过无数拥有复活能力的强者，被死之三兄弟彻底杀死。
　　而现在，有人打破了这个存在。
　　这个由无数小像素组成的方块人，果然有两把刷子。
　　就在老者震惊的时候，方启同样是感到惊讶。
　　刚才的死亡，他竟然没有看到任何受击动画，直接就是莫名其妙的死亡。
　　复活之后的方启，直接选择开启自己的另一项能力。
　　F3+B！
　　碰撞箱显示，启动！
　　随着方启打开碰撞箱显示，这个世界，在方启面前忽然大变样。
　　空气中忽然多了无数个看不见本体，但是却正在上下游离的小膨胀箱。
　　这些应该是灰尘。
　　面前的1440老头身上，也多了一个大的整体的碰撞箱。
　　方启咧嘴一笑，目光看向一旁空气中，多出来的三个碰撞箱。
　　和方启的猜测一样，MC的位格之高，远远超过现实世界。
　　死之三兄弟虽然无法观测，甚至无法对其造成影响，但是在MC的规则之下，对方依旧无所遁形！
　　注意到方启的目光，死之三兄弟终于开口。
　　站在最右侧的老三，默默开口。
　　没有声音，但是意念却直接传到到了方启的脑海中。
　　“吾，赐汝寂灭。”
　　“吾，赐汝的【复活】同样寂灭。”
　　不愧是掌握死亡叙事最高权柄的三个人。
　　一出手，不仅仅瞄准的是方启，还有方启能够复活的概念。
　　然而，死之三兄弟的力量，却是用错了地方。
　　以为内方启的复活，并非是他本身的能力。
　　方启的复活，其实是MC世界的能力。
　　是MC的世界让他复活，所以方启才能复活。
　　果不其然，就在老三话音落下的瞬间，方启再次瞬间死亡。
　　看着面前的死亡重生界面，方启笑了下，随手点了一下复活。
　　当那个方启完好无损的，再一次出现在众人眼前。
　　这一次，死之三兄弟算是直接沉默了。
　　死之三兄弟没有想到，自己纵横江湖万亿年。
　　这次竟然遇到了，能够规避他们能力的硬茬子。
　　“汝来找吾等，所为何事？”
　　死之三兄弟，老二上前一步，看向方启问道。
